# 02 · 기본 Module(M) 사전

모듈은 페이지 안에 들어가는 **내용 블록**입니다.
24개를 모두 넣지 않고, 선택한 CT와 실제 CASE 정보에 맞는 모듈만 사용합니다.

| 코드 | 모듈 | 역할 | 짧은 예시 | 필요 근거(Evidence) |
|---|---|---|---|---|
| **M01** | 질문 즉답 | 검색자의 질문에 첫 화면에서 바로 답함 | "하부만 손상됐다면 부분수리가 가능한 경우도 있습니다." | search_intent |
| **M02** | 핵심 요약 | 문제·판단·작업·결과를 짧게 압축 | 문제 / 판단 / 작업 / 결과 요약 | case.problem, judgement, work, result |
| **M03** | 문제·증상 | 현재 어떤 문제가 있는지 설명 | 썩음, 들뜸, 구멍, 누수 | case.problem |
| **M04** | 원인·발생 구조 | 문제가 생긴 이유와 진행 구조 | 반복적인 습기로 문틀 하부가 부식됨 | case.cause (관찰된 것만) |
| **M05** | 상태 구분 | 손상 정도를 나눠 설명 | 경미 / 부분손상 / 심한 손상 | 등급 기준 |
| **M06** | 전문가 판단 | 무엇을 보고 작업 방향을 정했는지 | 문틀 하부만 손상, 문짝·경첩은 정상 | case.judgement |
| **M07** | 수리·교체 기준 | 수리 가능한 조건과 교체 조건 | 부분복원 가능 / 전체교체 필요 | 기준표 |
| **M08** | 실제 작업 공정 | 해당 CASE에서 **실제로 수행한** 순서 | 철거 → 확인 → 재단 → 고정 → 마감 | case.work_steps |
| **M09** | 일반 해결방법 | 여러 현장에 적용 가능한 일반 수리방향 | 문틀 부식의 일반적인 보수 방향 | 일반 지식 |
| **M10** | 셀프시공 절차 | 사용자가 직접 작업하는 준비와 순서 | 제거 → 청소 → 재시공 → 확인 | 절차 + 안전 |
| **M11** | 대상·재료·자재 정보 | 대상·재료의 특징·용도·한계 | ABS, MDF, 실리콘, 퍼티 | material 사전 |
| **M12** | 공구 정보 | 공구의 기능과 사용 조건 | 임팩드릴, 샌더, 실리콘건 | tool 사전 |
| **M13** | 비교·선택 기준 | 방법·재료·제품의 차이와 선택 기준 | ABS와 MDF, 부분수리와 교체 | 비교 대상 2개 이상 |
| **M14** | 비용·시간 요소 | 비용·시간이 **달라지는 실제 이유** | 손상 범위, 접근성, 자재, 양생 | ※ 금액 단정 금지 |
| **M15** | 자가 확인 | 사용자가 안전하게 확인할 항목 | 흔들림, 들뜸, 물기, 개폐 상태 | 체크리스트 |
| **M16** | 안전·중단 기준 | 작업을 멈추고 전문가가 필요한 조건 | 전기·구조·심한 누수·고소작업 | 안전 규칙 |
| **M17** | 관리·예방 | 작업 후 관리와 재발 방지 | 물기 제거, 환기, 주기적 점검 | 관리 지침 |
| **M18** | 결과·한계 | 작업 후 달라진 점과 남은 한계 | 개폐 정상, 색상 차이는 일부 남음 | case.result, case.limit |
| **M19** | 실제 CASE 근거 | 설명을 실제 현장사례로 뒷받침 | "강남 문틀 교체 CASE에서는…" | case_id |
| **M20** | 사진·오버레이 | 사진으로 문제·판단·공정을 설명 | BEFORE/AFTER, 화살표, 설명박스 | image_ids |
| **M21** | FAQ | 추가로 궁금해할 질문에 답함 | "하부만 교체할 수 있나요?" | 중복 FAQ 금지 |
| **M22** | 관련 콘텐츠·내부링크 | CASE·WIKI·TOPIC 등 다음 페이지 연결 | 관련 사례·재료 정보 보기 | 실재하는 URL만 |
| **M23** | 지역·서비스 정보 | 실제 지역과 서비스 가능 범위 설명 | 강남 문틀수리 실제 사례 | 해당 지역 CASE 필수 |
| **M24** | CTA | 전화·문자·사진상담 등 다음 행동 안내 | 전체 사진과 근접 사진을 보내주세요 | 브랜드 CTA 규칙 |

## 모듈 그룹 (구현 시 컴포넌트 묶음)

| 그룹 | 모듈 | 렌더링 힌트 |
|---|---|---|
| 답변 | M01, M02 | 히어로 하단 Answer Box / Summary Card |
| 진단 | M03, M04, M05, M06, M07 | 증상 리스트 · 원인 다이어그램 · 상태 등급 카드 |
| 실행 | M08, M09, M10 | 스텝 타임라인 (번호 + 사진) |
| 정보 | M11, M12, M13, M14 | 스펙 테이블 · 비교 테이블 |
| 안전·사후 | M15, M16, M17, M18 | 체크리스트 · 경고 배너 · 결과 카드 |
| 근거 | M19, M20 | CASE 인용 카드 · 이미지 갤러리/오버레이 |
| 연결 | M21, M22, M23, M24 | 아코디언 FAQ · 관련 링크 그리드 · 지역 블록 · CTA |

## 금지 사항

- **M14**: 구체적 금액을 단정하지 않습니다. "달라지는 이유"만 서술합니다.
- **M23**: 실제 CASE가 없는 지역명을 쓰지 않습니다.
- **M21**: 다른 페이지와 거의 같은 FAQ를 복제하지 않습니다.
- **M24**: 모든 페이지에 동일한 CTA 문구를 반복하지 않습니다.

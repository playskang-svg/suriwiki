# 03 · CT별 필수·옵션 Module 조합

**필수 모듈**은 해당 CT의 뼈대이고,
**옵션 모듈**은 실제 입력정보와 검색 의도에 따라 AI가 보통 **2~4개**를 선택합니다.

| CT | 타입 | 필수 모듈 | 옵션 모듈 | 운영 메모 |
|---|---|---|---|---|
| **CT1** | 문제·해결형 | M01 · M03 · M04 · M09 | M05 · M06 · M07 · M15 · M16 · M17 · M19 · M20 · M21 · M24 | 원인 근거가 없으면 CT5 검토 또는 HOLD |
| **CT2** | 절차·튜토리얼형 | M01 · M10 · M16 · (M11 **또는** M12) | M03 · M05 · M15 · M17 · M18 · M19 · M20 · M21 · M22 | 준비물·안전·순서가 확인돼야 함 |
| **CT3** | 정보·지식형 | M01 · (M11 **또는** M12) | M04 · M09 · M13 · M14 · M16 · M17 · M19 · M20 · M21 · M22 | 재료·공구 등 설명 대상을 명확히 함 |
| **CT4** | 비교·선택형 | M01 · M13 · 비교대상 모듈 1개 이상 | M05 · M06 · M07 · M09 · M11 · M12 · M14 · M16 · M19 · M20 · M21 · M22 | 비교대상에 따라 M07/M09/M11/M12 선택 |

## 조건부 필수 승격

아래 조건에 해당하면 옵션 모듈이 **자동으로 필수**가 됩니다.

| 조건 | 승격되는 모듈 |
|---|---|
| 전기 · 가스 · 구조 · 심한 누수 · 고소작업이 관련됨 | **M16** 안전·중단 기준 |
| Page Type = CASE 이거나 source_case_id가 있음 | **M19** 실제 CASE 근거 |
| Page Type = AREA 이거나 URL에 지역 슬러그 포함 | **M23** 지역·서비스 정보 (+ 해당 지역 실제 CASE 필수) |
| Page Type = LANDING (전환 목적) | **M24** CTA |

## 검증 규칙 (빌드 타임에 체크)

```
1. required_modules ⊆ module_order          # 필수 모듈 누락 금지
2. 2 ≤ |selected_modules| ≤ 4               # 옵션 모듈 과다/과소 금지
3. ∀ m ∈ module_order : evidence(m) ≠ ∅     # 근거 없는 모듈 금지
4. CT4 → |비교대상| ≥ 2
5. CT6 → M08.steps 는 case.work_steps 와 1:1 일치
6. CT1 → case.cause ≠ ∅  (없으면 CT5 로 전환 또는 HOLD)
```

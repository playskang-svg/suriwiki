# 04 · 이미지 입력과 사용 규칙

사진은 **CASE별 원본 풀에 한 번만** 올리고, AI가 역할과 중복을 분류한 뒤
각 페이지의 **검색 질문에 맞는 이미지 세트**를 만듭니다.

| 단계 | 권장 기준 | 설명 |
|---|---|---|
| 원본 업로드 | 현장당 최대 **30장** | BEFORE · PROCESS · AFTER · 재료 · 공구 · 내부상태 등 |
| 사람 표시 | **반드시 사용** / **공개 금지** | AI가 놓치면 안 되는 사진과 비공개 사진만 표시 |
| AI 분류 | 역할 · 품질 · 유사도 | BEFORE / PROCESS / AFTER / MATERIAL / TOOL / EXCLUDE |
| LANDING 세트 | 보통 **4~6장** | 문제 → 판단/공정 → 결과 + 필요시 추가 근거 |
| 설명형 편집 | 크롭 · 콜라주 · 화살표 · 점선 · 설명박스 | 검색 질문에 맞는 오버레이로 정보 가치를 높임 |
| 금지 | **실제 내용 변경** | 없던 손상·공정·재료·결과를 만들어내지 않음 |

## 중복 방지 핵심

> 같은 원본을 1% 확대하거나 노이즈만 바꾸는 것이 아니라,
> **LANDING의 검색 질문에 맞춰 서로 다른 사진 조합과 설명형 오버레이**를 사용합니다.

### 이미지 세트 차별화 최소 조건

한 CASE에서 여러 페이지를 만들 때, 각 페이지의 이미지 세트는 아래 중 **2개 이상**이 달라야 합니다.

1. 사용된 원본 사진의 집합 (Jaccard 유사도 < 0.6)
2. 오버레이의 **설명 초점** (원인 표시 / 판단 근거 표시 / 공정 순서 표시 / 결과 비교)
3. 크롭 영역 및 구도 (전체 → 근접, 근접 → 콜라주)
4. 캡션 문장 (검색 질문에 맞춘 서로 다른 서술)

## 역할(role) 분류값

| role | 뜻 | 주 사용 모듈 |
|---|---|---|
| `BEFORE` | 작업 전 문제 상태 | M03, M04, M20 |
| `PROCESS` | 작업 중 공정 | M08, M10, M20 |
| `AFTER` | 작업 후 결과 | M18, M20 |
| `MATERIAL` | 사용한 자재 | M11 |
| `TOOL` | 사용한 공구 | M12 |
| `DETAIL` | 내부 상태·근접 | M05, M06 |
| `EXCLUDE` | 사용 안 함 (품질 불량·중복·공개 금지) | — |

## 오버레이 타입

| 타입 | 용도 | 예 |
|---|---|---|
| `arrow` | 특정 지점 지시 | 부식 시작 지점 |
| `box` | 영역 강조 | 하부 30cm 손상 범위 |
| `dashed` | 절단·교체 경계 | 재단 라인 |
| `callout` | 설명 박스 | "경첩부는 정상" |
| `compare` | BEFORE/AFTER 슬라이더 | 개폐 상태 변화 |
| `steps` | 번호 배지 | ①철거 ②확인 ③재단 |

## 저장 규격

```jsonc
// image (원본)
{
  "id": "img_...",
  "case_id": "case_...",
  "storage_path": "cases/case_.../orig/DSC0001.jpg",
  "role": "BEFORE",
  "must_use": false,        // 사람이 "반드시 사용" 표시
  "private": false,         // 사람이 "공개 금지" 표시
  "quality_score": 0.82,
  "phash": "e8f1...",       // 유사도 중복 검출용
  "alt_ko": "욕실 문틀 하부 부식 상태"
}

// image_variant (페이지용 편집본)
{
  "id": "iv_...",
  "image_id": "img_...",
  "page_id": "page_...",
  "crop": { "x": 0.1, "y": 0.4, "w": 0.6, "h": 0.5 },
  "overlays": [
    { "type": "box", "rect": [0.2,0.6,0.5,0.3], "label": "부식 범위" },
    { "type": "callout", "at": [0.7,0.2], "text": "경첩부는 정상" }
  ],
  "caption_ko": "문틀 하부 30cm 구간만 부식이 진행된 상태",
  "output_path": "pages/page_.../v1.webp"
}
```

## 접근성·성능

- 모든 이미지에 `alt_ko` 필수. CASE 사실 기반으로 작성(추측 금지).
- 출력 포맷 `webp`(fallback `jpeg`), 최대 폭 1600px, `loading="lazy"`, `sizes` 지정.
- 첫 화면 이미지 1장만 `priority`.

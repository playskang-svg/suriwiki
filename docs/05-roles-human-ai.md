# 05 · 사람과 AI의 업무 구분

| 담당 | 업무 | 구체 내용 |
|---|---|---|
| **사람** | 현장 사실 제공 | 지역 · 공간 · 대상 · 문제 · 판단 · 실제 작업 · 결과/한계 입력 |
| **사람** | 사진과 공개범위 | 원본 사진 업로드, "반드시 사용" · "공개 금지" 표시 |
| **사람** | 최종 확인 | AI가 잘못 이해한 사실 수정, 키워드 통합·분리와 **발행 승인** |
| **AI** | CASE 구조화 | 입력된 사실을 모듈에 사용할 수 있도록 정리 |
| **AI** | 키워드·LANDING 추천 | 지역·문제·재료·해결방법·장소·상황에서 후보 **6~8개** 기본 추천 |
| **AI** | CT·모듈 조립 | 검색 의도에 맞는 CT 선택 → 필수 모듈 → 실제 근거가 있는 옵션 모듈 선택 |
| **AI** | 이미지 구성 | 사진 분류, LANDING별 이미지 세트와 설명형 오버레이 제안 |
| **AI** | 중복·품질 검수 | 기존 URL·키워드와 비교해 **CREATE / UPDATE / MERGE / HOLD** 추천 |

## 경계선 (누가 절대 하지 않는 일)

**AI가 하지 않는 일**

- 없는 지역·가격·후기·공정·결과를 생성
- 사람의 "공개 금지" 사진 사용
- 사람 승인 없이 발행(`status: published`)
- 사실 근거 없이 필수 모듈 채우기

**사람이 하지 않아도 되는 일**

- 완성 원고 작성
- 키워드를 여러 칸에 나눠 입력
- 페이지마다 사진을 다시 업로드
- 모듈 순서를 손으로 배치

## 승인 상태 머신

```
draft ──(AI 생성 완료)──> review ──(사람 승인)──> published
  ▲                          │
  └────(사람 반려/수정 요청)──┘
                             └──(사실 근거 부족)──> hold
```

- `hold` 는 삭제가 아니라 **근거 대기** 상태입니다. 근거가 채워지면 `review` 로 복귀합니다.

# 01 · Content Type(CT) 정의

CT는 페이지가 **내용을 설명하는 방식**입니다.
같은 LANDING이라도 검색자가 묻는 질문에 따라 CT가 달라집니다.

| 코드 | 콘텐츠 타입 | 핵심 질문 | 대표 예시 | 주요 활용 |
|---|---|---|---|---|
| **CT1** | 문제·해결형 | 왜 이런 문제가 생겼고 어떻게 해결하는가? | 욕실 문틀이 썩는 원인과 해결방법 | LANDING · WIKI |
| **CT2** | 절차·튜토리얼형 | 무엇을 준비하고 어떤 순서로 작업하는가? | 욕실 실리콘 셀프시공 방법 | WIKI |
| **CT3** | 정보·지식형 | 이 대상·재료·공구는 무엇이고 어떤 특징이 있는가? | ABS 방문 특징, 실리콘 종류 | WIKI · TOPIC |
| **CT4** | 비교·선택형 | A와 B는 무엇이 다르고 무엇을 선택해야 하는가? | 부분수리와 전체교체 비교 | WIKI · LANDING |
| **CT5** | 진단·판단형 | 현재 상태에서 수리와 교체 중 무엇이 필요한가? | 썩은 문틀 하부만 수리할 수 있을까? | LANDING · WIKI · TOPIC |
| **CT6** | 사례·현장형 | 실제 현장에서 무엇을 보고 어떻게 판단·작업했는가? | 강남 욕실 문틀 하부 교체 사례 | CASE · LANDING |

## CT1과 CT5의 구분

- **CT1** 은 **원인과 해결방법**이 중심입니다. → "왜 썩었고, 어떻게 고치나"
- **CT5** 는 **현재 상태를 나누고 수리·교체 여부를 판단**하는 것이 중심입니다. → "내 상태면 수리인가 교체인가"

원인 근거(왜 생겼는지에 대한 실제 관찰)가 없으면 CT1을 쓰지 말고 CT5를 검토하거나 HOLD합니다.

## 검색 질문 → CT 매핑 힌트

| 검색어에 들어있는 신호 | 추천 CT |
|---|---|
| 원인, 왜, 이유, 해결방법, 고치는 법 | CT1 |
| 방법, 순서, 셀프, DIY, 하는 법, 시공법 | CT2 |
| ~란, 특징, 종류, 규격, 차이점 없이 단일 대상 설명 | CT3 |
| vs, 비교, 차이, 어떤 게 나은, 선택 | CT4 |
| 가능할까, 해야 하나, 기준, 판단, 교체 시기 | CT5 |
| 사례, 후기, 시공사례, 지역명 + 실제 작업 | CT6 |

> **규칙**: 페이지마다 **중심 CT는 1개만** 선택합니다. 다른 CT 요소는 옵션 모듈로만 보완합니다.

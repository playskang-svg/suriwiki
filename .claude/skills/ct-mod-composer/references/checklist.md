# 발행 전 게이트 체크리스트

각 항목을 실제로 확인하고 `pass` / `fail` + 근거를 기록합니다. 하나라도 fail이면 발행하지 않습니다.

## A. 사실성 (F)

```
□ F1 언급한 지역에 실제 CASE가 있다
□ F2 금액·기간을 단정하지 않았다 (M14는 "달라지는 이유"만)
□ F3 후기·평점·시공건수를 지어내지 않았다
□ F4 CASE에 없는 공정·재료·공구·결과가 없다
□ F5 사진의 실제 내용을 변경하지 않았다
□ F6 is_private=true 사진을 쓰지 않았다
□ F7 없는 자격·면허·인증을 표기하지 않았다
```

## B. 구조 (S)

```
□ S1 중심 CT 1개
□ S2 필수 모듈 전부 존재하고 각각 근거가 있다
□ S3 옵션 모듈 2~4개 (억지로 채우지 않았다)
□ S4 safety_flags 있으면 M16 포함, 접히지 않게 배치
□ S5 지역 언급 시 M23 포함 + 해당 지역 CASE 인용
□ S6 CT6이면 M08.steps == case.work_steps (개수·순서 일치)
□ S7 CT4이면 비교 대상 2개 이상
□ S8 CT1이면 case.cause 존재
```

## C. 중복 (D)

```
□ D1 dedupe_key 충돌 없음
□ D2 같은 CASE 파생 페이지와 diff_score ≥ 0.45
□ D3 같은 CT 다른 페이지와 모듈 순서 유사도 < 0.85
□ D4 FAQ 질문이 다른 페이지와 유사도 < 0.85
□ D5 이미지 세트 Jaccard < 0.6
□ D6 CTA 문구가 그룹 내에서 반복되지 않음
```

## D. 링크·SEO (L)

```
□ L1 내부링크 3~8개, 전부 실재 URL
□ L2 상위 TOPIC 또는 AREA에서 이 페이지로 오는 링크가 있다
□ L3 title 30~45자 / description 70~120자
□ L4 h1 1개
□ L5 모든 이미지 alt 있음 (CASE 사실 기반)
□ L6 FAQPage JSON-LD는 화면에 보이는 Q&A만
□ L7 AggregateRating/Review 마크업 없음 (실제 후기 없으므로)
```

## E. 표현

```
□ 금지 표현 없음 (100% 완벽 / 무조건 / 절대 / 업계 1위 / 최저가 / 국내 유일)
□ 위험 작업에 "누구나 쉽게 셀프로" 류 문구 없음
□ 타 업체 실명 비방 없음
□ 일반론을 늘려 쓴 문단 없음
□ 다른 페이지와 거의 같은 문단 없음
```

# 옵션 모듈 랭킹 점수

```
score(m) = 0.40·evidence_strength + 0.35·intent_fit + 0.15·uniqueness + 0.10·conversion_value
```

## evidence_strength

| 상태 | 값 |
|---|---|
| 해당 CASE 필드 비어 있음 | 0.0 |
| 한 문장 이하 단편 | 0.3 |
| 구체적 서술 (수치·부위·조건 포함) | 0.7 |
| 서술 + 사진 근거 | 1.0 |

**0.3 미만이면 점수와 무관하게 선택 금지.**

## intent_fit (검색 질문 유형 × 모듈)

| 질문 유형 | 높음(0.8~1.0) | 중간(0.4~0.7) | 낮음(0~0.3) |
|---|---|---|---|
| 원인 | M04 M05 M09 M17 | M03 M19 M20 | M08 M10 M12 |
| 셀프 방법 | M10 M11 M12 M15 M16 | M03 M17 M20 | M14 M23 |
| 판단 | M05 M06 M07 M19 | M03 M14 M20 M24 | M10 M12 |
| 비교 | M13 M07 M11 M14 | M09 M19 M20 | M08 M15 |
| 사례 | M08 M18 M20 M06 | M02 M11 M23 | M09 M13 |
| 지역 | M23 M19 M20 M24 | M02 M18 | M10 M12 M13 |
| 비용 요소 | M14 M05 M07 | M06 M19 M24 | M10 M11 |

## uniqueness

같은 space/target의 기존 발행 페이지에서 이 모듈이 쓰인 비율 `r` 에 대해 `1 - r`.

| TOPIC / AREA | M22=0.9, M23=0.9, 그 외 0.3 |

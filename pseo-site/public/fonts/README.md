# OG 이미지용 한글 폰트 폴더 (선택)

`lib/og-font.ts`는 기본적으로 빌드 시점에 Google Fonts에서 "Black Han Sans"를 자동으로
내려받아 씁니다. 인터넷이 막힌 환경(사내망, 일부 CI)에서 빌드하거나 다른 폰트를 쓰고
싶다면, 이 폴더에 `.ttf` 또는 `.otf` 폰트 파일을 하나 넣어주세요 — 있으면 그 파일이
Google Fonts보다 항상 우선 사용됩니다.

- 무료 상업적 이용 가능한 한글 폰트 예: Noto Sans KR(Google Fonts), Pretendard, 배달의민족 폰트 등
- 반드시 전체 한글 음절(가~힣)을 지원하는 폰트를 사용하세요 — 그렇지 않으면 일부
  지역명/키워드가 깨져 보일 수 있습니다.
- 폴더 안에 폰트가 여러 개면 그중 하나만(첫 번째로 읽히는 파일) 사용됩니다.

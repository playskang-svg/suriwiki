# 배경 이미지 폴더

이 폴더에 `1.jpg`, `2.jpg`, `3.jpg` ... 형식으로 배경 이미지를 넣어주세요.
(jpg/jpeg/png/webp 지원, 파일명은 숫자가 아니어도 되지만 숫자로 정렬하면 로테이션 순서를 예측하기 쉽습니다.)

- `lib/bg-images.ts`가 이 폴더를 읽어서, 키워드+지역 조합마다 결정적으로(랜덤 아님)
  이미지 하나를 골라 `app/api/og/[keyword]/[slug]/route.tsx`의 배경으로 씁니다.
- 이미지가 하나도 없어도 빌드는 깨지지 않습니다 — 배경 없이 단색 배경(#16264D)으로
  대체되어 렌더링됩니다. 다만 실제 서비스 전에는 최소 2~3장은 넣는 걸 권장합니다
  (같은 배경만 계속 반복되면 시각적으로 단조롭습니다).
- 시공 현장 사진처럼 저작권 문제가 없는 실제 이미지를 사용하세요.
